El chatbot usa esta información para responder consultas. A mayor detalle, mejor calidad de respuestas.

Estos datos se usan cuando un cliente pregunta cómo contactar al hotel, y también para armar los links de WhatsApp y email al confirmar una reserva.

Descripción del hotel
Texto libre para presentar el hotel. Incluí lo que lo diferencia: ubicación, estilo, tipo de huéspedes al que apunta, etc. El bot lo usa cuando alguien pregunta "¿cómo es el hotel?" o algo similar.
Servicios disponibles
Escribí los servicios en formato lista, un ítem por línea, empezando con guión (-).
Incluí detalles como horarios, condiciones o restricciones — cuanto más específico, mejor responde el bot.

Importante: el bot solo menciona estos servicios cuando el cliente los pregunta. No los incluye en la cotización de precios automáticamente.
Políticas y condiciones
Condiciones generales del hotel. El bot las usa para responder preguntas como "¿puedo llevar mi perro?" o "¿hay cancelación gratuita?".

Escribí una condición por línea con guión (-). Sé específico con plazos y excepciones para que el bot pueda dar respuestas precisas.

Configuración del bot

Controlá el estado, el tono y los límites del chatbot.

Estado del chatbot
Cargando…
Útil para desactivar el bot en temporada alta o cuando preferís atención 100% humana. Cuando está desactivado, usa el mensaje de "no disponible" configurado más abajo.
Personalidad
Define el tono general con el que el bot se comunica. Elegí el que mejor representa a tu hotel.
Podés ajustar detalles puntuales en el campo "Tono adicional" debajo sin cambiar la personalidad general.
🎩
Formal
Profesional y elegante. Trata de "usted". Para hoteles de categoría.
😊
Amigable
Cálido y cercano. Trata de "vos". Recomendado para la mayoría de los hoteles.
🤙
Casual
Relajado e informal. Puede usar emojis. Para hostels o alojamientos jóvenes.
Tono adicional — opcional
Instrucciones específicas que se suman a la personalidad elegida arriba. Usalo para ajustar detalles puntuales.
Tip: instrucciones cortas y específicas funcionan mejor que párrafos largos.
Información que el bot NO puede revelar
Temas que el bot debe ignorar aunque el cliente los pregunte directamente. El bot responderá que no tiene esa información disponible.
Ejemplos: "descuentos especiales para grupos", "tarifas de temporada anterior", "datos del propietario", "capacidad máxima del hotel".
Mensaje de bienvenida
Primer mensaje que ve el cliente al abrir el chat. Si lo dejás vacío se usa el mensaje por defecto del sistema.
Tip: mencioná qué puede hacer el bot para que el cliente sepa qué preguntar. No pongas información de contacto acá — el bot la comparte automáticamente cuando corresponde.
Mensaje cuando no puede responder
Se muestra cuando el cliente pregunta algo fuera del alcance del bot, o cuando el bot está desactivado. Aprovechalo para redirigir al cliente.
Si tenés el WhatsApp cargado en Datos de contacto, el bot incluye el link automáticamente al mencionar contacto.
